### 🎛️ How I build

My design background influences how I engineer. Visual identity, motion and UI taught me to care about how a system **feels**; software taught me to care about why it **works**.

When something breaks, I want visibility: **logs, state, data flow and reproducible evidence**. When something works, I want to understand enough of the system to improve it rather than treating it as magic.

> I don't collect technologies for a badge wall. I learn them when they help me understand a system or build a better product.
